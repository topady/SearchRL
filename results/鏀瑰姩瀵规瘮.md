## 3. retrieval_server.py

### 3.1 新增 import

```python
# new 新增
from modelscope import snapshot_download
```

### 3.2 `load_model` 函数 — 加入 ModelScope 模型下载

**old**：直接用 `transformers` 从 `model_path` 加载模型。

**new**：先检测 `model_path` 是否已存在于本地，如果不存在则通过 `modelscope.snapshot_download` 下载到 `./model_cache`，下载失败则回退到直接用 `transformers` 加载。原来的加载代码被注释保留。

```python
# new 的核心逻辑
local_model_path = model_path
if not os.path.exists(model_path):
    local_model_path = snapshot_download(model_path, cache_dir='./model_cache')
```

### 3.3 `DenseRetriever.__init__` — GPU 索引方式变更

**old**：使用多 GPU 分片

```python
co = faiss.GpuMultipleClonerOptions()
co.useFloat16 = True
co.shard = True
self.index = faiss.index_cpu_to_all_gpus(self.index, co=co)
```

**new**：改为单 GPU（GPU 0），手动设置临时内存 256MB

```python
res = faiss.StandardGpuResources()
res.setTempMemory(256 * 1024 * 1024)
self.index = faiss.index_cpu_to_gpu(res, 0, self.index)
```

**总结**：接入 ModelScope 加速国内模型下载；Faiss 从多 GPU 分片改为单 GPU 以适配只留 1 张 GPU 给检索服务的新部署方案（与 `retrieval_launch.sh` 中 `CUDA_VISIBLE_DEVICES=7` 配合）。

## 整体改动思路

new 版本的所有改动方向一致：**从通用开源版适配为特定集群部署版**：

1. **7+1 GPU 分离**：训练/评估用 7 卡，留 1 卡（GPU 7）专门运行检索服务。`train_grpo.sh` 和 `evaluate.sh` 都从 8 卡改为 7 卡，`retrieval_launch.sh` 新增 `CUDA_VISIBLE_DEVICES=7`。
2. **推理后端升级**：训练和评估脚本的 rollout 都从 `hf` 切换为 `vllm`（更快的推理）。
3. **集群网络适配**：训练和评估脚本都加入 NCCL 环境变量（bond0 网卡、禁用 IB/P2P、强制 IPv4）。
4. **ModelScope 集成**：`retrieval_server.py` 新增通过 ModelScope 下载模型的能力，适配国内网络环境。
5. **Faiss 单 GPU 化**：检索从多 GPU 分片改为单 GPU，与 7+1 分离方案一致。
6. **路径本地化**：数据路径、模型路径从 HuggingFace Hub ID / 占位符改为本地绝对路径。
